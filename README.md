# Dashboard-de-Vendas-do-Xbox-com-Excel-
 Dashboard de Vendas do Xbox com Excel
 Sobre o Projeto
Este projeto tem como objetivo desenvolver um dashboard de vendas no Microsoft Excel, transformando dados brutos em informações visuais claras e organizadas para facilitar a análise de desempenho comercial e apoiar a tomada de decisões.

O dashboard foi desenvolvido como parte de um desafio prático de análise de dados, com foco na organização, tratamento e visualização de informações utilizando recursos do Excel.

Objetivos

Organizar e estruturar os dados utilizados na análise.

Transformar dados em informações visuais de fácil interpretação.

Desenvolver um dashboard interativo para análise de vendas.

Facilitar a identificação de tendências e indicadores de desempenho.

Aplicar recursos do Excel para análise e visualização de dados.

Estrutura do Arquivo

O arquivo Excel está organizado nas seguintes abas:

Assets: recursos visuais utilizados na composição do projeto.

Bases: dados utilizados como fonte para as análises.

Cálculos: cálculos e informações auxiliares para construção dos indicadores.

Dashboard: painel visual para acompanhamento e análise dos resultados de vendas.
Resultados Esperados

Com o dashboard, é possível visualizar os dados de forma mais intuitiva, facilitar a interpretação dos resultados e tornar a análise de vendas mais organizada.

O projeto demonstra a aplicação prática do Excel na construção de ferramentas de análise de dados e na apresentação visual de informações relevantes para o negócio.
